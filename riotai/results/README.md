# Results README

This directory contains the summary results of the `kerchunk` vs `netcdf` benchmark runs across various file-count bins and workflow types. The results are organized into subdirectories by benchmark type, with each subdirectory containing a `summary.md` file that provides an overview of the benchmark results, representative plots, and validation summaries.

Refer to [20260702-overall-summary.md](riotai/results/20260702-overall-summary.md) for a high-level summary of the overall benchmark results, including key findings and known issues. For more detailed information on specific benchmark runs, refer to the individual `summary.md` files in the respective subdirectories.
